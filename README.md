# 🛡️ SafeHer – Women Safety Application

SafeHer is a smart women safety application designed to provide immediate assistance during emergencies through multiple SOS activation methods, real-time location tracking, and instant communication with trusted contacts.

The application focuses on enhancing personal safety by enabling users to quickly alert emergency contacts and share their live location during critical situations. SafeHer combines GPS technology, emergency response features, and user-friendly design to create a reliable safety companion.

## 🚀 Key Features

### 👤 User Profile Management

* Create and manage user accounts securely.
* Store personal information and emergency contact details.
* Customize safety preferences and emergency settings.

### 🚨 SOS Emergency Alerts

* Instantly trigger emergency alerts during dangerous situations.
* Send notifications to pre-registered emergency contacts.
* Provide quick access to emergency assistance features.

### 📍 Live GPS Location Tracking

* Share real-time location with emergency contacts.
* Enable continuous location updates during emergencies.
* Improve response time and user safety through accurate tracking.

### 📱 Multiple Emergency Triggers

* **Shake Detection:** Activate SOS alerts by shaking the device.
* **Voice Activation:** Trigger emergency mode using predefined voice commands.
* **Manual SOS Button:** One-tap emergency activation for immediate assistance.

### 📞 Fake Call Feature

* Generate a simulated incoming call to help users escape uncomfortable or unsafe situations.
* Provide a discreet method of handling potential threats.

### 🔊 Siren Alert System

* Activate a loud siren sound to attract nearby attention.
* Deter potential threats and alert people in the vicinity.

### 👥 Emergency Contact Management

* Add, edit, and manage trusted emergency contacts.
* Automatically notify contacts during emergencies.
* Maintain quick access to important contact information.

### 🔗 Backend API Integration

* Integrated REST APIs for user management and emergency services.
* Ensures seamless communication between application components.
* Supports real-time data exchange and notification delivery.

## 🛠️ Technologies Used

* Android Development
* GPS & Location Services
* REST APIs
* Backend Integration
* Mobile Application Development

## 🎯 Project Outcome

SafeHer aims to empower women with a reliable and accessible safety solution by combining emergency alerts, live location sharing, intelligent trigger mechanisms, and rapid communication tools. The application provides users with greater confidence and security during daily activities and travel.
